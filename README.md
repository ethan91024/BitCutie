# 比特萌 BitCutie

16bit自訂桌面寵物

**目前版本是介面原型**：桌面收起時只看到灰色像素蛋，右鍵展開照顧面板；養成數值、AI 生成與圖片上傳尚未實作。

## 啟動

```powershell
npm install
npm run tauri dev
```

也可以用 `npm run dev` 在瀏覽器預覽介面；透明桌面視窗和原生拖曳需要透過 Tauri 執行。

## 目前可操作的介面

- 收起狀態只有像素蛋；左鍵可拖曳視窗，右鍵在旁邊開啟獨立面板。拖曳蛋時，面板會跟著移動且不遮住蛋。
- 面板中的「設定」與「更新」會開啟各自的介面頁；「退出」會關閉程式。
- 餵食、喝水、看醫生、散步、跑步、撫摸、睡覺，以及圖片生成、寵物選擇、漫遊/固定設定皆為停用的介面預覽。

## 第一個里程碑驗收條件

1. 收起時只有灰色像素蛋可見，透明桌面視窗沒有一般視窗邊框。
2. 左鍵拖曳可移動寵物視窗；在蛋上按右鍵會展開控制面板，收起按鈕或 Escape 返回蛋的狀態。
3. 面板呈現飽食、口渴、心情、健康和所有照顧入口；未實作的功能明確停用。
4. 設定頁呈現上傳圖片生成、寵物選擇及漫遊/固定設定；不讀取或上傳圖片。
5. 更新頁可檢視原型版本資訊；退出可關閉應用程式。

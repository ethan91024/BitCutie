# 桌面寵物介面原型規格

## 產品方向

- 桌面上平常只顯示寵物本體；可以拖曳位置，未來支援自由漫遊或固定。
- 對寵物按右鍵，在寵物旁邊展開獨立照顧面板；面板不得遮住寵物。
- 面板跟隨寵物視窗移動；空間不足時切換到寵物另一側，並盡量留在目前螢幕的可用範圍內。
- 寵物與 UI 使用 **16-bit 像素風格**。還沒有建立/選擇角色時，顯示灰色像素蛋，中央有黑色問號。
- 目前只做介面原型，不實作養成數值、圖片上傳、LLM/圖像生成、角色切換或漫遊行為。

## 收起狀態

- 顯示透明、無邊框、置頂的桌面視窗，視覺內容只有灰色像素蛋。
- 左鍵拖曳可移動寵物視窗；蛋上按右鍵開啟旁邊的獨立面板。
- 提示文字只在游標懸停時顯示，平時不增加桌面雜訊。

## 照顧面板

- 面板視窗目標尺寸約 220×620 CSS 像素；以原面板寬度減半為設計基準。窄版採兩欄狀態卡和照顧入口、精簡頂欄，依可見蛋圖邊緣留小間距，上緣靠近蛋頂端；設定等長內容在面板內捲動。
- 顯示寵物尚未建立的空狀態和灰色像素蛋。
- 狀態區：飽食、口渴、心情、健康。
- 照顧入口：餵食、喝水、看醫生、散步、跑步、撫摸、睡覺。
- 底部功能：設定、更新、退出。
- 尚未實作的遊戲功能以停用按鈕呈現，狀態指標顯示未建立，避免假裝有真實資料。

## 設定頁

- 顯示圖片上傳生成說明，突出「上傳圖片 → LLM 理解角色 → 生成 16-bit 多動作/多角度角色」的產品賣點。
- 顯示寵物選擇區和預設神秘像素蛋。
- 顯示自由漫遊/固定位置兩種桌面行為模式。
- 目前以上述內容做介面展示；圖片、角色選擇和行為設定皆不啟用。

## 視覺原則

- 以安靜的暖灰、鼠尾草綠與少量柔和輔色構成；資訊分組清晰、留白充足。
- 使用像素輪廓、方角和少量像素裝飾呼應角色，不仿照參考圖的密集表格、按鈕排列或角色構圖。
- 收起狀態不顯示面板或狀態列；面板只在右鍵開啟後出現。
